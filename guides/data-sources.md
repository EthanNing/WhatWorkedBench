MIT-BIH source attribution is Moody and Mark (2001), *The impact of the MIT-BIH Arrhythmia Database*, and PhysioNet. Newman network data retain their original dataset citations and the source page’s scientific-use terms. Consult those terms when adapting the data to a different use. Source manifests preserve all original license statements.

Native computation code and references are released for research reproducibility. The recorded source and preparation paths in provenance metadata identify the original experiment; the executable replay resolves its inputs relative to `native/`.
